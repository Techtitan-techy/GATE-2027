# 🤝 Contributing to GATE 2027 CSE Vault

First off, thank you for considering contributing to the **GATE 2027 CSE Preparation Vault**! Community contributions help thousands of aspirants across India achieve their dream of cracking GATE with **AIR < 100** and securing admissions into IISc, IITs, or top PSUs.

---

## 🌟 How You Can Contribute

1. **Add High-Yield Standard Resources**:
   - Standard reference textbooks recommended by IIT professors.
   - Verified topper handwritten notes (Ace Academy, Made Easy, GateNotes, Ravindrababu Ravula, Amit Khurana).
   - Topic-wise PYQ solutions with step-by-step explanations.
2. **Mindmaps & Cheat Sheets**:
   - Visual summary sheets for complex algorithms, proofs, and formulas.
3. **Fix Typos or Broken Links**:
   - Report or correct broken markdown links in the [README.md](./README.md) or [SITEMAP.md](./SITEMAP.md).
4. **Curate Quality Free Lectures**:
   - Recommend exceptional NPTEL or YouTube video lecture playlists for specific topics.

---

## 📝 Contribution Workflow

1. **Fork the Repository**:
   Click the **Fork** button at the top-right corner of [https://github.com/Techtitan-techy/GATE-2027](https://github.com/Techtitan-techy/GATE-2027).

2. **Clone Your Fork**:
   ```bash
   git clone https://github.com/<your-username>/GATE-2027.git
   cd GATE-2027
   ```

3. **Create a Dedicated Branch**:
   ```bash
   git checkout -b feature/add-new-resource
   ```

4. **Add Your Materials**:
   - Ensure books/notes are organized into their corresponding subject directory (e.g., `06 — Operating Systems/`).
   - Please ensure files are clean and legible.
   - If adding files larger than 100 MB, configure Git LFS tracking.

5. **Commit and Push**:
   ```bash
   git add .
   git commit -m "feat(subject): add standard reference material for [topic]"
   git push origin feature/add-new-resource
   ```

6. **Submit a Pull Request**:
   - Open a PR against the `main` branch of `Techtitan-techy/GATE-2027`.
   - Include a brief description of the resource and why it's beneficial for GATE CSE 2027.
